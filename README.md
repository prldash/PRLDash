# PRLDASH

**Mine Pearl (PEARL) on your NVIDIA RTX graphics card.**

PRLDASH is a desktop miner for Pearl. Download it, paste your wallet address and press Start.

- Website: <https://prldash.com>
- Downloads: [Releases](https://github.com/prldash/PRLDash/releases)
- Setup guide: <https://prldash.com/start/>
- Earnings calculator: <https://prldash.com/earnings/>
- Community: [Discord](https://discord.gg/xaAGWHVAVt) · [X](https://x.com/prldash)

## Requirements

- 64-bit Windows 10 or 11, Linux, or HiveOS
- NVIDIA GeForce RTX 30, 40 or 50 series card with a current NVIDIA driver
- A Pearl wallet address ([how to get one](https://prldash.com/start/))

## Fees

PRLDASH has no fee until 1 December 2026. From then on it keeps 0.5% of mined Pearl. Your mining pool charges its own fee as well. See the [FAQ](https://prldash.com/#faq).

## About this repository

This repository hosts the PRLDASH release files. The miner's source code is not published here.

To report a problem, open an issue, ask in the #support channel on [Discord](https://discord.gg/xaAGWHVAVt) or write to admin@prldash.com.

PRLDASH is an independent project and is not affiliated with NVIDIA.
